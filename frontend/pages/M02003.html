문항 추가 방법

유형을 한 번 클릭하면 선택만 바뀝니다. 추가 버튼·더블클릭·Ctrl+Enter로 선택한 위치에 넣습니다.

위치 목록에서 선택 문항의 위·아래, 현재 섹션 끝 또는 설문 맨 끝을 고릅니다. 본문 맨 아래 추가 버튼은 항상 설문 끝에 넣습니다.

설문 편집 도움말

왼쪽 유형을 한 번 클릭하면 선택만 바뀝니다. 추가 버튼·더블클릭·Ctrl+Enter로 지정한 위치에 넣으며, 본문 맨 아래 추가는 설문 끝에 넣습니다.

섹션 목록으로 이동하고, 화살표로 본문의 맨 위·아래를 확인합니다. 접기·펼치기는 전체 섹션에 적용하며, 섹션별 버튼으로 개별 조절할 수 있습니다.

선택 문항의 위·아래 삽입 버튼으로 중간에 문항을 넣습니다. 문항 번호는 자동으로 정리됩니다.

보기의 표시 문구는 응답자에게 보이며, 결과 코드는 결과 코드형 내보내기에 사용됩니다. 입력 번호는 번호 선택 방식에서 사용하는 별도 번호입니다.

내용은 저장 버튼을 눌러야 보관됩니다. 변경 취소는 마지막 저장 상태로 되돌리며, 공개 반영은 다시 확정해야 합니다.
